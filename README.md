# lifeplan-sim

高精度ライフプランシミュレーター。純粋TypeScriptの決定論エンジン + モンテカルロラッパーで、手取り・給付金・住宅ローン・教育費・NISAを暦年ベースでシミュレートします。React + Vite製のダッシュボードUIから、世帯データの編集・複数シナリオの比較まで行えます。

> **免責事項**: 本ツールは税務相談・投資助言ではありません。計算結果は各種制度の簡易モデルによる概算であり、正確性を保証しません。実際の税額・保険料・給付額は税理士・社会保険労務士等の専門家、または公的機関にご確認ください。

## 使い方

エンジン(テスト・デモ):

```powershell
npm install
npm test        # ゴールデンテスト含む全テスト
npm run demo    # サンプル世帯の30年キャッシュフロー表
npm run lint    # エンジン純粋性チェック含むESLint
npm run typecheck
```

UI(ダッシュボード):

```powershell
cd app
npm install
npm run dev      # 開発サーバー起動
npm run build    # 型チェック + 本番ビルド
npm run lint     # oxlint
```

UIは `profile.sample/` のデータを初期値として読み込みます。「データ編集」タブでの変更はブラウザの`localStorage`にのみ保存され、サーバーやリポジトリには送信されません。

## 設計

設計書: [docs/lifeplan-schema-design.md](docs/lifeplan-schema-design.md)

- **エンジン純粋性**: `engine/` はブラウザAPI・`Date.now()`・`Math.random()` 禁止(ESLintで強制)。現在日時・乱数は引数で注入
- **データとロジックの分離**: 税制・社保の数値はすべて `rules/<year>.json`。全値に一次情報の `_source`(URL+確認日)付き
- **個人データ分離**: `profile/` はgitignore。サンプルは `profile.sample/`
- **金額は整数円**: 丸め規則(標準報酬の50銭ルール、課税所得の千円未満切捨て等)は実装コメントに根拠を明記
